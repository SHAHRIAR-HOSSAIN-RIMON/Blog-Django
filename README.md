# 📝 Chat Blog with Django

A basic blog platform where users can create and manage posts. Built using Django to practice backend development and explore project-building with authentication and CRUD operations.

## 📌 Features

- User registration and login system
- Create, edit, and delete blog posts
- View all posts from all users
- Django admin panel for managing content

## ⚙️ Tech Stack

- **Backend:** Django (Python)
- **Database:** SQLite (default)
- **Frontend:** HTML, CSS 
- **Authentication:** Django’s built-in auth system
